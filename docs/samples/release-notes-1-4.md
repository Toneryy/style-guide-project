# Itmotify 1.4 — 16 октября 2026 года

Теперь рекомендации учитывают, какие треки вы пропускаете: если пропустить трек в первые 30 секунд, похожие треки будут попадаться реже.

## Новое

- Подборка дня обновляется каждое утро в 06:00 по вашему времени. Она находится на главной странице.
- В один плейлист можно добавить до 10 000 треков. Раньше можно было добавить до 1000.
- С подпиской Premium треки звучат в качестве до 320 килобит в секунду.

## Улучшения

- Результаты поиска по каталогу появляются в среднем за 0,8 секунды вместо 1,6 секунды.

## Исправления

- Скачанные треки больше не пропадают из **Медиатеки** после обновления приложения для Android.
