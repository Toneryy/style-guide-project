# Создать плейлист

Метод `POST /v1/playlists` создаёт пустой плейлист в медиатеке текущего пользователя. Метод доступен только пользователям с аккаунтом: на запрос гостя API вернёт ошибку `401`.

## Запрос

```http
POST /v1/playlists
```

| Заголовок | Обязателен | Значение |
| --- | --- | --- |
| `Authorization` | Да | `Bearer <токен доступа>` |
| `Content-Type` | Да | `application/json` |

Параметры передаются в теле запроса.

| Параметр | Тип | Обязателен | Описание |
| --- | --- | --- | --- |
| `title` | `string` | Да | Название плейлиста, от 1 до 100 символов. Должно отличаться от названий других плейлистов пользователя |
| `is_public` | `boolean` | Нет | Видят ли плейлист другие пользователи и гости. По умолчанию `false` |
| `description` | `string` | Нет | Описание плейлиста, до 300 символов |

## Пример запроса

```bash
curl -X POST https://api.itmotify.example/v1/playlists \
  -H "Authorization: Bearer <токен доступа>" \
  -H "Content-Type: application/json" \
  -d '{"title": "Для пробежки", "is_public": true}'
```

## Ответ

Код `201 Created` — плейлист создан. В теле ответа — созданный плейлист.

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | `string` | Идентификатор плейлиста |
| `title` | `string` | Название плейлиста |
| `is_public` | `boolean` | Публичный ли плейлист |
| `description` | `string` | Описание или `null`, если описания нет |
| `tracks_count` | `integer` | Количество треков. У нового плейлиста — `0` |
| `created_at` | `string` | Дата и время создания в формате ISO 8601 |

```json
{
  "id": "pl_8f3k2m9q",
  "title": "Для пробежки",
  "is_public": true,
  "description": null,
  "tracks_count": 0,
  "created_at": "2026-10-16T15:30:00+03:00"
}
```

## Ошибки

| Код | Причина | Что сделать |
| --- | --- | --- |
| `400` | Параметр `title` пустой или длиннее 100 символов, `description` длиннее 300 символов | Проверьте длину строк |
| `401` | Нет заголовка `Authorization`, или срок действия токена истёк | Получите новый токен методом `POST /v1/auth/refresh` |
| `409` | У пользователя уже есть плейлист с таким названием | Предложите пользователю другое название |
