# itmotify-api

Серверная часть Itmotify: REST API для поиска по каталогу, плейлистов, истории прослушиваний и подписок. API используют веб-приложение и приложения Itmotify для Android и iOS.

## Требования

- Docker 24 или выше с Docker Compose v2
- Git 2.40 или выше
- Python 3.12 — только если запускаете тесты без Docker

## Быстрый старт

1. Склонируйте репозиторий и перейдите в его папку:

    ```bash
    git clone https://git.itmotify.example/backend/itmotify-api.git
    cd itmotify-api
    ```

2. Создайте файл настроек из примера:

    ```bash
    cp .env.example .env
    ```

3. Запустите API, базу данных и кеш:

    ```bash
    docker compose up -d
    ```

4. Создайте таблицы в базе данных:

    ```bash
    docker compose exec api alembic upgrade head
    ```

API заработает по адресу `http://localhost:8080`. Чтобы проверить, откройте `http://localhost:8080/health` — сервис ответит `{"status": "ok"}`. Интерактивная документация API — по адресу `http://localhost:8080/docs`.

## Настройка

Настройки задаются переменными окружения в файле `.env`.

| Переменная | Назначение | Пример | Обязательна |
| --- | --- | --- | --- |
| `DATABASE_URL` | Адрес базы данных PostgreSQL 16 | `postgresql://itmotify:itmotify@db:5432/itmotify` | Да |
| `REDIS_URL` | Адрес кеша Redis 7 | `redis://cache:6379/0` | Да |
| `JWT_SECRET` | Ключ для подписи токенов доступа | — | Да. Получите у владельца сервиса, в репозиторий не добавляйте |
| `RECS_SERVICE_URL` | Адрес сервиса рекомендаций | `http://recs:8090` | Нет. Без него рекомендации отключены |
| `LOG_LEVEL` | Подробность журнала: `debug`, `info`, `warning`, `error` | `info` | Нет. По умолчанию `info` |

## Тесты

```bash
docker compose exec api pytest
```

Все тесты должны пройти, в последней строке вывода — `passed` без `failed`.

## Структура

| Папка | Что внутри |
| --- | --- |
| `app/api/` | Обработчики запросов, по файлу на группу методов |
| `app/models/` | Модели базы данных |
| `app/services/` | Бизнес-логика: поиск, плейлисты, подписки |
| `migrations/` | Миграции базы данных Alembic |
| `tests/` | Автотесты |
