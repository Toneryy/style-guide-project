# Примеры документов

Здесь собраны документы Itmotify, написанные по этому руководству: по одному на каждый вид документа. Используйте их как образец, когда пишете похожий документ.

Каждый пример построен по шаблону. В конце примера есть раздел «Разбор примера»: какие правила руководства применены и где именно.

| Вид документа | Пример | Читатель | Шаблон |
| --- | --- | --- | --- |
| Справочная статья | [Создать плейлист](../examples/create-playlist.md) | Пользователь | [Справочная статья](../templates/help-article.md) |
| Ответы на частые вопросы | [Подписка Premium: частые вопросы](faq-premium.md) | Пользователь | [Справочная статья](../templates/help-article.md#ответы-на-частые-вопросы) |
| Требования в ТЗ | [Требования к функциям: плейлисты](requirements-playlists.md) | Заказчик, разработчики, тестировщики | [Требование](../templates/requirement.md) |
| Требования в ТЗ: до и после | [Требования ТЗ: до и после](../examples/nfr-rewrite.md) | Заказчик, разработчики, тестировщики | [Требование](../templates/requirement.md) |
| README сервиса | [itmotify-api](readme-api.md) | Разработчик | [README](../templates/readme.md) |
| Описание метода API | [Создать плейлист — POST /v1/playlists](api-create-playlist.md) | Разработчик клиентского приложения | [Описание метода API](../templates/api-method.md) |
| Заметки о выпуске | [Itmotify 1.4](release-notes-1-4.md) | Пользователь | [Заметки о выпуске](../templates/release-notes.md) |

Примеры описывают одни и те же функции Itmotify с разных сторон. Например, создание плейлиста есть в справочной статье, в требованиях ФТ-10 и ФТ-16 и в описании метода API. Термины, ограничения и сообщения об ошибках в них совпадают — так руководство обеспечивает единообразие документации.
