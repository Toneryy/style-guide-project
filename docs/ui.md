# Интерфейс и действия пользователя

Раздел для авторов справки и инструкций: как называть элементы интерфейса Itmotify и описывать действия с ними.

## Названия элементов

- Пишите название так, как оно написано на экране, с теми же прописными буквами. Выделяйте жирным, без кавычек: нажмите **Создать плейлист**.
- Тип элемента не указывайте, если он ясен из контекста: «Нажмите **Сохранить**», а не «Нажмите на кнопку „Сохранить“».
- Указывайте тип, если без него непонятно, что искать: «Включите переключатель **Скачивать только по Wi-Fi**».
- Если у кнопки нет подписи, а только значок, называйте ее по всплывающей подсказке и описывайте значок: «Нажмите **Нравится** (значок сердца)».
- Если интерфейс изменился, обновите название во всех статьях. Список статей, где встречается элемент, ищите поиском по репозиторию.

## Глаголы действий

Для каждого действия используем один глагол на всех платформах.

| Элемент | Глагол | Пример |
| --- | --- | --- |
| Кнопка, ссылка, пункт меню | нажмите | Нажмите **Скачать**. |
| Поле ввода | введите, укажите | Введите название плейлиста. |
| Выпадающий список, вариант | выберите | Выберите **Качество звука** → **Высокое**. |
| Переключатель | включите, выключите | Выключите **Автовоспроизведение**. |
| Флажок | отметьте, снимите отметку | Отметьте **Сделать плейлист публичным**. |
| Раздел, страница, окно | откройте | Откройте **Медиатеку**. |
| Трек, карточка в списке | перетащите | Перетащите трек выше в списке. |
| Длинная страница | прокрутите | Прокрутите страницу до блока **Похожие исполнители**. |

Не используйте разговорные и платформенные глаголы.

| Неправильно | Правильно |
| --- | --- |
| ~~кликните, тапните, ткните~~ | нажмите |
| ~~залогиньтесь, авторизуйтесь~~ | войдите |
| ~~зарегистрируйте аккаунт~~ | зарегистрируйтесь |
| ~~загрузите трек на телефон~~ | скачайте трек |

## Путь по меню

Если нужно пройти два уровня меню и больше, перечислите их через стрелку «→» с пробелами:

Откройте **Профиль** → **Настройки** → **Воспроизведение**.

## Шаги инструкции

1. Каждый шаг – отдельный пункт нумерованного списка.
2. В шаге одно действие или два, если они выполняются на одном экране.
3. Если после шага что-то меняется на экране, напишите об этом отдельным предложением в том же пункте: «Откроется окно **Новый плейлист**».
4. Последний шаг заканчивается результатом, по которому читатель понимает, что все получилось.

## Платформы

Itmotify работает в браузере, в приложениях для Android и iOS. Если действия на платформах различаются, разделите инструкцию подзаголовками третьего уровня: «В браузере», «В приложении». Если действия одинаковые, не упоминайте платформу.

## Положение и цвет

Не описывайте элемент только положением или цветом: «нажмите зеленую кнопку справа». Цвет и расположение отличаются на разных экранах, а некоторые читатели их не различают. Пишите название элемента, а положение добавляйте как подсказку: «Нажмите **Слушать** под обложкой плейлиста».

## Клавиши

Сочетания клавиш оформляйте расширением `pymdownx.keys`: `++ctrl+s++` отображается как ++ctrl+s++. Пишите сочетание для Windows, а для macOS – в скобках, если оно отличается: «Чтобы найти трек, нажмите ++ctrl+k++ (++cmd+k++)».
