# Глоссарий

Термины Itmotify и то, как их писать в документации. Если нужного термина нет, добавьте его в том же Pull Request, где он впервые понадобился. Термины расположены по алфавиту: сначала латиница, потом кириллица.

## Продукт и пользователи

| Термин | Значение | Не пишем |
| --- | --- | --- |
| Itmotify | Название сервиса. Пишется латиницей с прописной, не склоняется | ~~ITMOtify, Итмотифай~~ |
| Аккаунт | Учётная запись пользователя в Itmotify | ~~учётка, акк, профиль~~ в значении аккаунта |
| Бесплатный тариф | Доступ к Itmotify без подписки: с рекламой и ограничениями | ~~free-версия, фри, базовая подписка~~ |
| Гость | Человек, который открыл Itmotify без входа в аккаунт | ~~аноним, незарегистрированный юзер~~ |
| Музыкальный редактор | Сотрудник, который ведёт каталог и составляет редакционные подборки | ~~контент-менеджер, модератор~~ |
| Подписка Premium | Платная подписка: без рекламы, со скачиванием треков и расширенными рекомендациями | ~~премиум, прем, платная версия~~ |
| Пользователь | Человек с аккаунтом Itmotify | ~~юзер, клиент, слушатель~~ |
| Профиль | Страница пользователя с именем, статистикой и публичными плейлистами | — |

## Музыка и функции

| Термин | Значение | Не пишем |
| --- | --- | --- |
| Альбом | Набор треков, который выпустил исполнитель | ~~релиз, пластинка~~ |
| Исполнитель | Музыкант или группа, чьи треки есть в каталоге | ~~артист, автор~~ |
| История прослушиваний | Список треков, которые пользователь слушал, по времени | ~~история, лог прослушиваний~~ |
| Каталог | Все треки, альбомы и исполнители, доступные в Itmotify | ~~база, библиотека~~ |
| Медиатека | Раздел с плейлистами пользователя, скачанными треками и треками с отметкой **Нравится** | ~~моя музыка, коллекция~~ |
| Отметка **Нравится** | Отметка, которую пользователь ставит треку. В ТЗ и документации для разработчиков допустимо «лайк» | ~~лайкнуть, сердечко~~ в справке |
| Плейлист | Список треков, который составил пользователь | ~~плей-лист, список воспроизведения~~ |
| Подборка | Список треков, который составил Itmotify или музыкальный редактор | ~~плейлист~~ в этом значении |
| Подборка дня | Персональная подборка из 30 треков, которая обновляется каждый день | ~~микс, моя волна~~ |
| Рекомендации | Треки, исполнители и подборки, которые Itmotify предлагает по истории прослушиваний | ~~советы, рекомендашки~~ |
| Скачать | Сохранить трек на устройство, чтобы слушать без интернета | ~~загрузить, закачать~~ |
| Трек | Одна музыкальная композиция | ~~трэк, песня, композиция~~ |

## Сокращения

| Сокращение | Расшифровка |
| --- | --- |
| API | Интерфейс программирования приложений |
| ИИ | Искусственный интеллект. В русском тексте не пишем ~~AI~~ |
| ML | Машинное обучение (machine learning) |
| MVP | Минимально жизнеспособный продукт — первая версия с основными функциями |
| ТЗ | Техническое задание |
| ФТ, НФТ | Функциональное и нефункциональное требование |
